## 1.3. Домовленості команди
Основним каналом комунікації команди є спільний чат у месенджері Telegram. Асинхронні стендапи проводяться щопонеділка та щочетверга: кожен учасник коротко звітує про виконану роботу та наявні блокери. Максимальний час відповіді на робочі повідомлення в денний час становить 24 години. Усі артефакти зберігаються у спільній папці на Google Drive та дублюються в репозиторій на GitHub.

## 1.4. Методологія роботи
| Рівень | Що застосовує наша команда | 
| :--- | :--- |
| **Методологія** | Полегшений Scrum: п'ять двотижневих спринтів, Sprint Planning, Demo, Retro, ротація ролей  | 
| **Методи** | Опис вимог через user stories; рецензування артефактів за чек-листами; трасування «вимога → кейс → дефект» | 
| **Прийоми** | Асинхронний standup у два рядки; ретроспектива Start/Stop/Continue; одна задача — один виконавець — один рецензент |
