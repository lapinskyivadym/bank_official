# Звітні матеріали Спринту 3 — «Тест-кейси та звіти про дефекти»

**Команда:** «ФінКит» (lapinskyivadym/bank_official)  
**Продукт:** Система онлайн-банкінгу «ФінКит» (demo: ParaBank)

## Зміст досьє v3
1. `README.md` — поточний навігаційний файл, статистика та покриття.
2. `test-cases.xlsx` — спроєктовані тест-кейси (40 шт.), матриця покриття (Coverage) та результати рецензування (Review).
3. `execution-log.xlsx` — журнал виконання тест-кейсів із фіксацією середовища та статусів.
4. `tasks.md` — таблиця розподілу задач між учасниками команди.
5. `retro.md` — протокол ретроспективи (Start/Stop/Continue).
6. Трекер дефектів (GitHub Issues) — звіти про дефекти, знайдені під час виконання.

🔗 **Посилання на трекер:** [Усі баг-репорти Спринту 3 (мітка sprint:3)](https://github.com/lapinskyivadym/bank_official/issues?q=is%3Aissue+label%3Asprint%3A3)
