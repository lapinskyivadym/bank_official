## Об'єкти рецензування
Згідно із завданням проведено перевірку трьох розроблених моделей:
1. `01_account.drawio` (Відкриття рахунку)
2. `02_transfer.drawio` (Переказ коштів)
3. `03_credit.drawio` (Оформлення кредиту)

## Чек-лист перевірки нотації BPMN 2.0
| Критерій перевірки | Статус | Коментар |
| :--- | :---: | :--- |
| Наявність початкових та кінцевих подій | ✅ Відповідає | Усі події ініціації та завершення позначені коректно (зелені та червоні кола відповідно). |
| Використання пулів та доріжок | ✅ Відповідає | Межі відповідальності учасників (клієнт, банк, процесинг) розділені правильно. |
| Потоки керування | ✅ Відповідає | Використовуються виключно для послідовності дій всередині одного пулу. |
| Потоки повідомлень | ✅ Відповідає | Коректно відображають взаємодію та передачу даних між різними пулами. |
| Логіка шлюзів XOR, AND | ✅ Відповідає | Розгалуження за даними XOR та паралельні потоки AND налаштовані логічно, замкнуті відповідними шлюзами синхронізації. |
| Артефакти даних | ✅ Відповідає | Документи прив'язані пунктирними лініями асоціації без стрілок. |

## Висновок
Усі три BPMN-моделі відповідають стандарту розробки BPMN 2.0 та повністю покривають бізнес-логіку, описану у вимогах до продукту. Критичних дефектів або порушень нотації не виявлено.
