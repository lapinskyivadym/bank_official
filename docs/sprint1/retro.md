# Ретроспектива (Спринт 1)

**Продукт:** "ФінКит"  
**Спринт:** 1  
**Скрам-майстер:** Мельниченко Артемій

## Аналіз Спринту за форматом Start/Stop/Continue

### Start (Почати робити)
* Активніше використовувати асинхронні стендапи щопонеділка та щочетверга, щоб усі були в курсі прогресу без зайвих зідзвонів.
* Покращити комунікацію в telegram-чаті команди: стежити за тим, щоб відповіді на робочі питання надходили в межах регламентованих 24 годин.

### Stop (Припинити робити)
* Припинити призначати задачі без попереднього обговорення та підтвердження виконавцем у чаті.
* Уникати ситуацій, коли тестування та рецензування моделей залишається на останній день спринту.

### Continue (Продовжити робити)
* Продовжити використовувати draw.io для моделювання BPMN-схем, оскільки це дозволяє легко експортувати файли у PNG для документації.
* Продовжити практику чіткого розподілу на одну задачу - один виконавець - один рецензент.
