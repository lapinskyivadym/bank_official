## 2. Структура директорії (Артефакти спринту)

Нижче наведено перелік файлів інкременту, що знаходяться у цій папці (`docs/sprint2/`), та їхнє призначення.

| Файл / Документ | Опис артефакту |
| :--- | :--- |
| `test-plan.md` | **План тестування:** стратегія, опис 7 рівнів, застосовні типи тестування, обмеження середовища та обґрунтування незастосовних типів. |
| `SRS-1.1.md` | **Оновлена специфікація:** виправлений текст вимог до продукту «ФінКит» із журналом змін на початку документа. |
| `requirements-defects.xlsx` | Локальна резервна копія реєстру дефектів вимог (вивантаження з Google Sheets). |
| `tasks.md` | **Трекінг завдань:** розподіл підзадач між ролями, статуси виконання, оцінка в годинах та закріплення рецензентів. |
