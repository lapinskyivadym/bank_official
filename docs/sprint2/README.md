# Звітні матеріали Спринту 2 — «Аудит вимог і стратегія тестування»

**Продукт:** Система онлайн-банкінгу «ФінКит»  
**Відповідальний за збірку (README):** Фризюк Д. (Інженер з тестування)

---

## 1. Незалежний аудит специфікації (SRS 1.0)

Відповідно до регламенту (п. 4.9), первинний аудит вимог проводився кожним учасником команди повністю незалежно. Після цього всі персональні знахідки були зведені в єдиний реєстр.

🔗 **Повний реєстр дефектів:**  
Усі дані збережено у файлі `requirements-defects.xlsx` у цій директорії.  
*(Якщо команда веде онлайн-версію, вставте сюди посилання на Google Таблицю з доступом "Усі, хто має посилання — Читач")*

**Навігація по аркушах таблиці:**
*   `Реєстр` — фінальна зведена таблиця підтверджених дефектів.
*   `Спірні` — протокол обговорення заперечених дефектів та ухвалені рішення.
*   `Розподіл розділів` — матриця закріплення блоків SRS за конкретними аудиторами.
*   `Лапінський`, `Мельниченко`, `Обозюк`, `Фризюк` — індивідуальні робочі аркуші кожного члена команди.

## 2. Структура директорії (Артефакти спринту)

Нижче наведено фактичний перелік файлів інкременту, що знаходяться у цій папці (`docs/sprint2/`).

| Файл | Опис артефакту |
| :--- | :--- |
| `README.md` | Цей навігаційний файл зі структурою директорії та посиланнями. |
| `SRS-1.1.md` | **Оновлена специфікація:** виправлений текст вимог до продукту «ФінКит» із журналом змін на початку документа. |
| `requirements-defects.xlsx` | **Реєстр дефектів вимог:** зведена таблиця, список спірних дефектів, розподіл розділів та індивідуальні аркуші аудиторів. |
| `tasks.md` | **Трекінг завдань:** розподіл задач між ролями, статуси виконання та закріплення рецензентів. |
