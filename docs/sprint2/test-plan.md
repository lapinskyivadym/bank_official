# План тестування продукту «ФінКит» (Спринт 2)

**Автор:** [Фризюк Денис] (Інженер з тестування) · **Рецензент:** [Обозюк Олександр] · **Затверджує:** [Мельниченко Артемій] · **Статус:** ЗАТВЕРДЖЕНО, [15.10.2026]

## 1. Продукт і межі тестування

**Продукт:** Система онлайн-банкінгу «ФінКит» для фізичних осіб (управління рахунками, транзакції, онлайн-кредитування) + Java-модуль бізнес-логіки `ua.kpi.tzyapz.finkit` (`LoanCalculator`, `TransferValidator`, `AccountLedger`)[cite: 86, 89, 90].
**Стратегічний пріоритет замовника:** Безпечне кредитування онлайн без відвідування відділення та 100% захист від подвійних списань при переказах[cite: 87, 88].

**У межах тестування:** Функціональні вимоги F-10…F-140 (згідно зі специфікацією SRS 1.1), інтерфейси GUI-10…GUI-80, перевірка бізнес-правил BL-10…BL-80, нефункціональні вимоги (P, S, U, D)[cite: 123, 124, 125, 126].
**Поза межами:** Мобільний застосунок, робочі місця операціоніста/ризик-менеджера, розсилка реальних SMS/Email (на демо вони не надсилаються, тестується лише інтерфейсна логіка)[cite: 121, 122].

**Об'єкти тестування:**
1. Публічне demo ParaBank: https://parabank.parasoft.com/parabank/index.htm (основне середовище)[cite: 89].
2. Java-модуль бізнес-логіки: v1.0.0 (поточна версія) та v2.0.0 (для регресійного тестування)[cite: 89].
3. Резервний екземпляр: GlobalSQA Banking Project[cite: 89].

## 5. Інструменти, середовище, тестові дані

*   **Основне середовище (UI):** Демонстраційний сервіс ParaBank (https://parabank.parasoft.com)[cite: 89]. **Увага:** дані регулярно скидаються[cite: 89, 90].
*   **Резервне середовище:** GlobalSQA Banking Project (на випадок повної недоступності ParaBank)[cite: 89].
*   **Локальне середовище (Модуль):** Java 17, Maven 3.9, JUnit 5[cite: 122].
*   **Тестові дані:** 
    *   Реєстрація та логін тестового користувача з префіксом команди (наприклад, `T4-Ivanov`)[cite: 81].
    *   Суми переказів на межах: 0 грн, -100 грн, сума більша за баланс, ліміт 50 000 грн[cite: 123, 125].
    *   Кредитний калькулятор: суми 499 грн, 500 грн, 1 000 000 грн, 1 000 001 грн[cite: 123, 125].
*   **Інструменти:** JUnit 5, Mockito, JaCoCo, JMH; JMeter/Postman; Chrome DevTools (Network).

## 6. Ризики і припущення

1. **Скидання даних Demo:** БД ParaBank періодично очищується[cite: 89, 90]. Тому кожен тест-кейс має створювати клієнта і рахунки з нуля на етапі *Preconditions*. Наскрізні сценарії виконуються в рамках однієї сесії.
2. **Спільне середовище:** На публічному демо інші студенти можуть створювати конфліктні дані[cite: 90]. Обов'язкове використання унікальних логінів (префікс команди)[cite: 81].
3. **Мовне питання:** Інтерфейс ParaBank англомовний. Усі англійські тексти розглядаються як дефекти локалізації відносно специфікації SRS (де вимагається українська)[cite: 122].
4. **Обмеження навантаження:** Тести типів 16, 18, 24 (навантажувальне, стрибкове, умов гонок) не запускаються на живому ParaBank через заборону перевантаження публічних демо[cite: 81]. Вони виконуються виключно на локальному Java-модулі або резервному стенді.
5. **Непідключені сповіщення:** SMS та E-mail сповіщення на демо-сервері фізично не відправляються. Тестується виключно коректність появи повідомлення про успішну відправку на рівні інтерфейсу.
