# BPMN-моделі бізнес-процесів системи «ФінКит» (Sprint 1)

У цій директорії розміщено моделі ключових бізнес-процесів онлайн-банкінгу «ФінКит», розроблені за стандартом нотації **BPMN 2.0** відповідно до вимог Спринту 1 та каталогу продукту (розділ 4.3).

---

## Перелік бізнес-процесів

1. **Process 1: Відкриття рахунку** (`01_account`)
2. **Process 2: Переказ коштів** (`02_transfer`)
3. **Process 3: Оформлення кредиту** (`03_credit`)

---

## Інструменти та формати

* **Інструмент моделювання:** [diagrams.net](https://app.diagrams.net/) (draw.io, стандартна бібліотека BPMN 2.0).
* **Формати файлів:**
  * `.drawio` — вихідні редаговані файли діаграм у форматі XML.
  * `.png` — графічні знімки для швидкого перегляду в документації та демонстрації.

---

## Файли моделей

| Файл | Модель процесу | Основні учасники |
|---|---|---|
| `01_account.drawio` / `.png` | Відкриття рахунку | Клієнт, Система, Операціоніст |
| `02_transfer.drawio` / `.png` | Переказ коштів | Клієнт, Система, Операціоніст, Процесинговий центр |
| `03_credit.drawio` / `.png` | Оформлення кредиту | Клієнт, Система, Ризик-менеджер, Операціоніст |

> **Примітка:** файли `.drawio` використовуються як вихідний код для редагування, а `.png` — для швидкого перегляду у звітності та документації.

---

## Як відкрити вихідні файли (.drawio)

1. Відкрийте онлайн-редактор [app.diagrams.net](https://app.diagrams.net/) у браузері.
2. У верхньому меню оберіть **File** → **Open from** → **Device** (або на початковому екрані натисніть **Open Existing Diagram**).
3. Виберіть потрібний файл `.drawio` з папки `sprint1/bpmn-model/`.
4. Щоб схема повністю вписалася в робочу область, натисніть `Ctrl + Shift + H` (або **View** → **Reset View**).

## Позначення, використані в моделях

* **Пул** — прямокутна рамка, що позначає окремого незалежного учасника процесу (Клієнт, Банк «ФінКит», Процесинговий центр).
* **Доріжка** — горизонтальна підкатегорія всередині пулу банку для розподілу відповідальності (Система, Операціоніст, Ризик-менеджер).
* **Потік керування (суцільна стрілка)** — послідовність виконання дій виключно всередині одного пулу.
* **Потік повідомлень (пунктирна стрілка)** — взаємодія та передача даних між різними пулами (позначає передані форми, рішення або сповіщення).
* **Шлюзи:**
  * Помаранчевий ромб із запитанням — виключне АБО за даними (`XOR`).
  * Ромб із позначкою `+` — паралельне розгалуження та синхронізація (`AND`).
  * Ромб із подвійним колом — шлюз за подіями (`Event-Based XOR`).
* **Події:**
  * Зелене коло — початкова подія (ініціація процесу).
  * Жовте коло — проміжна подія (отримання повідомлення, таймер очікування 7 днів).
  * Червоне коло з товстою межею — кінцева подія (успішне завершення або відхилення).
* **Артефакти даних** — документ із загнутим кутом (Заявка, Платіжне доручення, Кредитна заявка), з'єднаний пунктирною лінією асоціації без стрілки.
