# Тестування продукту «ФінКит» 🏦

Цей репозиторій призначений для зберігання артефактів, тестової документації та автотестів, створених під час виконання командних лабораторних робіт з дисципліни «Технології забезпечення якості програмних засобів» (ТЗЯПЗ) у КПІ.

## Про продукт
**«ФінКит»** — це система онлайн-банкінгу для фізичних осіб. 
У рамках курсу ми виконуємо роль відділу забезпечення якості (QA), проводимо аудит вимог, складаємо тестову документацію та покриваємо бізнес-логіку автотестами.
